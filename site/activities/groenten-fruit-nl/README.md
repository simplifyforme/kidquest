# Groenten en fruit herkennen

Quiz de vocabulaire en néerlandais belge. Observe la photo et choisis le nom avec son article. Quatre questions portent sur les fruits et quatre sur les légumes, au sens culinaire.

Les huit images de `assets/` ont été générées avec OpenAI ImageGen pour KidQuest, puis recadrées et exportées en JPEG. Le dossier contient tous les médias utilisés par le quiz.
