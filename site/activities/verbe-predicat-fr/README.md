# Les détectives de la phrase · Verbe et prédicat

Activité débutant, environ 8 ans, dans **Français — École**. Pack autonome `verbe-predicat-fr` version 1 pour KidQuest 0.9.0+.

32 petits défis sur huit phrases familières : retrouver le verbe conjugué, donner son infinitif, retrouver le prédicat et distinguer les deux formes du verbe. Les mêmes phrases réapparaissent pour relier les trois notions. Exemples : « Lina mange une pomme. », « Le chat dort. », « Le chien est petit. »

## Repères pour débuter

- **Verbe conjugué** : il va avec le sujet. « Lina mange » → mange ; « Nous regardons » → regardons.
- **Infinitif** : c’est le nom du verbe. Astuce : « il faut manger », « il faut dormir ».
- **Prédicat** : ce qu’on dit du sujet. Dans ces phrases simples, garde le verbe et les mots qui vont avec lui : « mange une pomme », « est petit ». Dans « Le chat dort », le prédicat est simplement « dort ».

Un verbe ne dit pas seulement une action : « être » permet aussi de dire un état. Pour éviter les pièges à ce niveau, les phrases n’ont qu’un verbe au présent, pas de négation, de temps composé ni de complément de phrase facultatif à déplacer. Les mots à classer sont toujours présentés avec leur contexte.

Chaque consigne est autonome et contient un petit repère. Chaque correction redonne la réponse et explique le lien entre les notions. Le moteur tire huit questions par partie et varie automatiquement les jeux compatibles (QCM, écriture, lettres, mots à ordonner, associations, memory…). L’ordre et la couverture des trois notions ne sont pas garantis dans une seule partie ; les rappels restent donc présents quelle que soit la question tirée. Pas de parcours progressif imposé ou de nouveau moteur.

## Livraison et suivi

- Nouvelle carte 🕵️, distincte de « La chasse aux verbes », qui reste inchangée.
- Aucun script, média distant ou changement de programme. « Vérifier les mises à jour » suffit sur KidQuest 0.9.0+, puis fonctionnement hors ligne.
- Points, sessions et visibilité utilisent le suivi existant. Conserver les 32 IDs de questions dans les futures versions.
- Le catalogue et le manifeste avec SHA-256 sont publiés par GitHub Actions après fusion.
