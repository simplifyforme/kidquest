# Kleurenheld · Leer de kleuren

Activité de Nederlands (`nl-BE`) pour apprendre 11 couleurs : rood, blauw, geel, groen, oranje, paars, roze, bruin, zwart, wit et grijs.

- 11 questions visuelles : reconnaître la couleur d’une grande pastille, sans mot écrit sur l’image.
- 11 questions de vocabulaire : retrouver le mot néerlandais depuis le français, avec les modes compatibles attribués automatiquement (saisie, lettres, associations, etc.).
- Chaque correction relie le mot néerlandais à sa traduction française. Les noms de couleurs sont employés seuls, sans article, comme réponses à « Welke kleur? ».
- Une partie KidQuest tire huit questions ; rejouer permet de rencontrer les autres couleurs et interactions.

## Images et accessibilité

Les 11 PNG ont été dessinés spécifiquement pour KidQuest avec Pillow : cercles de couleurs unies, mêmes dimensions et fond clair, contour sombre permettant de distinguer le blanc. Aucun visuel tiers, texte révélant la réponse, service externe ou image générée par IA. Les fichiers sont stockés dans `assets/` et restent utilisables hors ligne après téléchargement vérifié.

L’exercice visuel entraîne la reconnaissance des couleurs et dépend de leur perception et du rendu de l’écran ; les questions de vocabulaire ne dépendent pas de cette perception. Le texte alternatif décrit la forme sans révéler la bonne réponse.

## Installation

Pack version 1, moteur existant de KidQuest 0.9.0+. « Vérifier les mises à jour » suffit ; pas de nouvel installateur. IDs permanents, aucun changement de SQLite, des points, de l’historique ni des préférences parentales. Icône 🎨 dans le catalogue.
